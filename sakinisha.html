Sakinisha

Mahitaji na hatua za kujenga mkusanyaji kutoka chanzo.

Mahitaji

  • LLVM 18 au mpya (C API) — imejaribiwa kwenye LLVM 22.1 (Arch Linux) na LLVM 18 (Windows).
  • Rust (toleo jipya zaidi).
  • Clang — kwa majaribio ya ujumuishaji.

Hakuna kiunganishi kinachohitajika kwa mnyororo wa kujikusanya. Mbegu (--exe) hutoa ET_EXEC tuli moja kwa moja, bila gcc, ld, clang, wala libc.

Pakua

●bash
git clone https://github.com/lugha-swa/swa.git
cd swa

Jenga

●bash
cargo build --release
cargo test    # majaribio 227

Kusanya mpango wa Swa

●bash
# Kusanya faili ya Swa
cargo run -- programu.swa

# Kutumia stage1 ya kujitegemea
./stage1 msingi/msomaji.swa
