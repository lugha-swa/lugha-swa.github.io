Msimbo unaoonekana kama Kiswahili

Huu ni mpango halisi wa Swa — unasoma kwa urahisi kwa mzungumzaji wa Kiswahili.

salamu.swa 
husisha C::stdio

W0 salamu(N8* jina) {
    andika("Habari, %s!\n", jina);
}

W0 hesabu_na_onyesha(N32 a, N32 b) {
    N32 jumla = a + b;
    N32 tofauti = a - b;
    andika("%d + %d = %d\n", a, b, jumla);
    andika("%d - %d = %d\n", a, b, tofauti);
}

salamu("Dunia");
hesabu_na_onyesha(15, 7);

Kiswahili 100%

Maneno muhimu 13 ya Kiswahili — hakuna Kiingereza katika sintaksia. Aina za nambari hutambuliwa kisintaksia kwa herufi kubwa.

Inajikusanya (0% gap)

Mnyororo wa kujikusanya umefungwa kabisa: baiti za mkono → mbegu → stage1-exe → stage2-exe == stage3-exe, sawa kwa baiti — bila kiunganishi wala libc.

Kizalishe asilia cha x86-64

Hutoa ELF ya x86-64 moja kwa moja, bila LLVM wala mkusanyaji msaidizi. LLVM iko kwa majukwaa zaidi.

Familia 5 za aina

N (namba), A (asili), D (desimali), B (buli), W (upana wa mashine) — upana wowote: N8–N128, D16–D80, B1–B64, W0–W64, n.k.

Kumbukumbu ya moja kwa moja

tenga (tenga kumbukumbu), achilia (achilia) — hakuna mkusanyaji wa takataka.

Ilioandikwa kwa Swa yenyewe

Msomaji, mchanganuzi, mkaguzi, na kizalishe vyote vimeandikwa kwa Swa — mkusanyaji unajikusanya.

Mnyororo wa Kujikusanya

Kila hatua hutoa kizazi kinachofuata — hadi mkusanyaji unajithibitisha yenyewe.

baiti za mkono
kwanza — baiti 393 zilizoandikwa kwa mkono
→
mbegu
mbegu.bin — kutoka hex
→
stage1-exe
ET_EXEC tuli, moja kwa moja
→
stage2-exe == stage3-exe
sawa kwa baiti — uthibitisho

Hakuna gcc, ld, clang, wala libc popote kwenye mnyororo.

Anza

1. Pakua

git clone https://github.com/lugha-swa/swa.git
cd swa

2. Jenga

cargo build --release
cargo test          # majaribio 227

3. Kusanya mpango

cargo run -- programu.swa

# au kwa stage1 ya kujitegemea
./stage1 msingi/msomaji.swa

Mahitaji: LLVM 18+ (C API) · Rust · Clang. Hakuna kiunganishi kinachohitajika kwa mnyororo wa kujikusanya.
