Swa

Lugha ya kupanga yenye sintaksia kamili ya Kiswahili.

Swa ni mkusanyaji wa lugha ya mifumo unaojikusanya. Inakusanya moja kwa moja hadi msimbo wa mashine: kwa njia asilia inayotoa ELF ya x86-64 bila LLVM wala mkusanyaji msaidizi, na pia kwa njia ya LLVM kwa majukwaa zaidi.

Mfano

husisha C::stdio

N32 kadirifu(N32 x) {
    kama (x > 0) {
        rudisha 1;
    }
    sivyo {
        kama (x < 0) {
            rudisha -1;
        }
    }
    rudisha 0;
}

N32 main() {
    andika("kadirifu(-5) = %d\n", kadirifu(-5));
    andika("kadirifu(42) = %d\n", kadirifu(42));
    rudisha 0;
}

Kujenga

Mahitaji: LLVM 18+ (C API), Rust, na Clang. Hakuna kiunganishi kinachohitajika kwa mnyororo wa kujikusanya.

cargo build --release
cargo test

Kusanya faili ya Swa:

cargo run -- programu.swa

Hali ya mradi

  • Msomaji, mchanganuzi, mkaguzi, na kizalishe asilia vimekamilika.
  • Mnyororo wa kujikusanya umefungwa: baiti za mkono, mbegu, stage1-exe, na stage2-exe == stage3-exe sawa kwa baiti.
  • Majaribio 227 yanapita (146 ya maktaba, 80 ya ujumuishaji, 1 ya nyaraka).
  • Dereva wa Rust (LLVM) ni wa majaribio — mnyororo wa uzalishaji ni mbegu/exe pekee.
