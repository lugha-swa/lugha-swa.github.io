# lugha-swa.github.io

Tovuti ya shirika la **lugha-swa** — makao rasmi ya lugha ya kupanga ya **Swa**.

Swa ni lugha ya mifumo yenye sintaksia kamili ya Kiswahili, mkusanyaji wa kujikusanya
unaokusanya moja kwa moja hadi msimbo wa mashine.

- Msimbo: https://github.com/lugha-swa/swa
- Tovuti: https://lugha-swa.github.io
