Jifunze Swa

Mwongozo mfupi wa sintaksia ya Swa, kwa mfano.

Aina za nambari

Swa ina familia tano za aina: N (namba), A (asili, bila ishara), D (desimali), B (buli), na W (upana wa mashine; W0 ni bila thamani).

●aina.swa
N32 umri = 25;
N64 idadi_ya_watu = 8000000000;
D64 wastani = 3.14;
B1  imewashwa = 1;
N8  herufi = 'A';

Kazi

Kazi hutangazwa kwa aina ya kurudi, jina, na vigezo. W0 inaashiria kazi isiyorudisha thamani.

●kazi.swa
N32 jumlisha(N32 a, N32 b) {
    rudisha a + b;
}

W0 salamu(N8* jina) {
    andika("Habari, %s!\n", jina);
}

Mtiririko wa udhibiti

kama na sivyo ndizo pekee za masharti. Tawi-jingine huandikwa kwa kuingiza kama ndani ya sivyo.

●udhibiti.swa
N32 kadirifu(N32 x) {
    kama (x > 0) {
        rudisha 1;
    }
    sivyo {
        kama (x < 0) {
            rudisha -1;
        }
    }
    rudisha 0;
}

// Kitanzi cha wakati
W0 hesabu_hadi(N32 n) {
    N32 i = 0;
    wakati (i < n) {
        andika("%d\n", i);
        i = i + 1;
    }
}

Miundo

Muundo hutangazwa kwa muundo. Sehemu zake hupatikana kwa . au ->.

●muundo.swa
muundo Nukta {
    N32 x;
    N32 y;
};

N32 pata_x(Nukta p) {
    rudisha p.x;
}

W0 weka_x(Nukta* p, N32 v) {
    p->x = v;
}

Kumbukumbu

Kumbukumbu hutengwa kwa tenga na kuachiliwa kwa achilia. Hakuna mkusanyaji wa takataka.

●kumbukumbu.swa
W0 mfano_kumbukumbu() {
    N32* p = tenga N32;
    *p = 42;
    achilia(p);
}

Maktaba ya mfuatano

Swa inakuja na maktaba ndogo ya kawaida: hesabu, mifuatano, orodha, mpangilio, na ramani. Kila faili la maktaba linaweza kuunganishwa kwa husisha.

●mfuatano.swa
husisha { mfuatano.swa }

N32 main() {
    N8 b[16];
    nakili_mfuatano(b, "habari");
    andika("urefu: %d\n", urefu_wa_mfuatano(b));
    rudisha 0;
}
